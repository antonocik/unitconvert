# UnitConvert

Aplikasi konversi satuan lengkap (panjang, berat, suhu, mata uang statis, dan data digital).

## Fitur
- Konversi panjang (m, km, cm, mm, inci, feet, yard)
- Konversi berat (kg, g, lb, oz)
- Konversi suhu (C, F, K)
- Konversi mata uang (statis: USD, IDR, EUR, JPY)
- Konversi data digital (bit, byte, KB, MB, GB, TB)
- Hasil tampil langsung tanpa submit form
- Responsif

## Menjalankan
Buka `index.html` di browser, atau:
```bash
python3 -m http.server 8080
```
